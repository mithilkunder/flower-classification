# Flower Classification using Machine Learning

## Project Overview

This project classifies Iris flowers into:

- Setosa
- Versicolor
- Virginica

using Machine Learning algorithms.

## Algorithms Used

- Logistic Regression
- Decision Tree

## Libraries

- Pandas
- NumPy
- Seaborn
- Matplotlib
- Scikit-learn
- Joblib

## How to Run

Install requirements

```bash
pip install -r requirements.txt
```

Train model

```bash
python flower_classification.py
```

Predict

```bash
python predict.py
```
